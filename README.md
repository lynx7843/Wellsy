# Wellsy

Wellsy is a personal health tracking app that brings nutrition, activity, hydration and daily habits together in one place. It gives you a clear view of your day and helps you build consistent, healthy routines.

## Features

- **Today dashboard**: a daily overview of readiness, energy balance, steps, hydration and medication
- **Nutrition**: log meals, track calories and macros, and monitor micronutrients and water intake
- **Activity**: track calories burned, steps, distance and workouts, with streaks and milestones
- **Habits**: hydration goals, medication schedules with reminders, and habit streaks
- **Accounts**: sign up and sign in securely, with a personal profile (age, weight, height, activity level) used to set goals
- **Sync**: data is stored in the cloud and available across devices

## Tech Stack

- **Frontend**: Flutter (Dart)
- **Data storage**: MongoDB Atlas
- **Authentication**: MongoDB Atlas
- **Fonts**: Google Fonts (Plus Jakarta Sans)

## Getting Started

```bash
git clone <repository-url>
cd Wellsy
flutter pub get
flutter run
```
